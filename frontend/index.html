Big 3D assets

EMStudio's own 3D viewer (to annotate and check an asset). A whole glb or cloud over the threshold does not load by itself: the viewer asks, and proposes the tileset when the model has one. A tileset opens at its root and refines on request; in automatic mode it stays under the memory ceiling.

Images (IIIF)

Where the images live: the address of an IIIF Image API service (Cantaloupe, in the StratiGraph stack). An image's identifier is its sha256, so only the host goes here. Left empty, everything works as before: no thumbnails, no broken frames.
